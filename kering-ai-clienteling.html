设计说明
· Layer 0（关键能力支撑）— 数据治理、Eval评估、FinOps等横切能力贯穿所有层，确保AI系统好用、可控、可规模化。
· Layer 1（模型与基础设施层）— LLM Gateway统一接入多模型，向量数据库与缓存层提供AI运行的基础设施保障。
· Layer 2（AI能力层）— Context Engineering、RAG 2.0、MCP工具层三大原子能力，让AI看得更全、检索更准、连接真实世界。
· Layer 3（智能体层）— Orchestration Agent统一编排Client/Moment/Voice三个专用Agent，实现从单点工具到多Agent协同的跃迁。
· Layer 4（应用层）— 四个应用交付业务价值，品牌配置层实现一套AI系统服务12个品牌的调性与数据隔离。

Part 03

重点方案详设

从旅程地图中选出三个最高优先级的方案，层层递进：知道客户是谁 → 知道怎么说 → 知道何时行动。

01
Client 360 — AI客户画像

将散落在CRM、企微、门店系统中的客户信息，整合为一张SA可理解的360度画像。

用户门店SA、品牌客户经理
场景一：客户标签从多源数据中自动提取客户偏好标签（风格、品类、价格带、颜色），替代SA手动打标
场景二：接待前画像摘要客户到店前，系统自动生成"这个人是谁"的自然语言摘要，SA花30秒掌握全貌
场景三：接待中实时查阅SA通过自然语言快速查询客户偏好与历史（"她上次买了什么？"），秒级返回精准答案

技术要点

• 标签体系分层：一级（品类）→ 二级（具体产品）→ 三级（属性：颜色/材质/风格）
• 同一标签多源交叉验证：企微提到 + 购买记录 = 高置信度

指标与评测

• 标签提取F1-score ≥ 0.80：人工标注100条对话，对比AI提取结果
• 标签覆盖率 ≥ 70%：活跃客户有≥5个标签
• SA标签采纳率 ≥ 60%：确认数 / 总处理数

技术要点

• 检索策略：向量相似度（语义匹配）+ 关键词精确匹配（品牌/品类名）+ 时间衰减（近期权重高）
• Chunk按对话轮次切分，保留上下文完整性，每chunk附时间戳+来源元数据
• 摘要Prompt结构化约束：必须包含近期购买、偏好风格、重要个人事件、待跟进事项
• 幻觉防护：每个事实点必须可追溯到原始记录，无法追溯的标注"待确认"

指标与评测

• RAG Recall@10 ≥ 0.90：关键信息是否在前10条检索结果中
• 摘要人工评分 ≥ 4.0/5.0：SA盲评完整性、准确性、可读性
• 幻觉率 ≤ 5%：逐句追溯
• SA阅读完成率 ≥ 80%：打开后停留 ≥ 15秒

技术要点

• 查询改写：将SA口语化提问转为结构化查询（"她喜欢什么颜色" → 检索偏好标签中的颜色字段）
• 支持多轮追问，继承上一轮客户身份
• 延迟约束：端到端 < 2秒（检索 < 500ms + LLM生成 < 1s），需流式输出
• 降级策略：检索失败时返回客户基础标签页；LLM超时返回检索原文片段

• SA日均查询次数 ≥ 3次/人：反映实际使用频率

品牌沟通助手 — 品牌调性内容生成

让SA的每一次触达都带着品牌温度，而不是群发模板。

用户门店SA、品牌CRM运营
场景一：节日/生日关怀节日、生日、纪念日到来时，AI结合客户画像和品牌调性自动生成个性化祝福，替代群发模板
场景二：新品推荐文案新品上架时，AI结合客户偏好和产品卖点生成个性化推荐话术，帮SA精准种草
场景三：购后关怀内容购买后按时间节点自动生成差异化关怀——第3天保养建议、第14天体验回访、第30天搭配推荐

技术要点

• 品牌调性结构化注入：每个品牌维护独立System Prompt，含语气风格、称呼习惯、禁用词列表、长度约束、emoji规则
• 客户画像融合：将Client 360的偏好标签注入Prompt，让内容从"亲爱的客户"变成"王姐，上次您说想找一款适合日常通勤的包"
• 多版本输出：每次生成2-3个版本供SA选择，降低单版本不满意的风险
• 置信度分级：高置信度（品牌匹配度>0.9）直接可用；低置信度标注"建议SA审核后发送"

指标与评测

• 品牌调性一致性评分 ≥ 4.0/5.0：LLM-as-Judge评估生成内容是否符合品牌调性标准
• SA直接采纳率 ≥ 50%：生成内容无需修改直接发送的比例
• 客户回复率提升 ≥ 20%：对比AI生成 vs 群发模板的客户回复率差异

• 产品知识RAG：从品牌产品知识库中检索对应品类的保养知识、搭配建议，不允许AI凭空编造保养方法

• 客户收到关怀后的回复率 ≥ 15%：反映关怀内容的温度和共鸣感

03
Smart Moments — 关键时刻引擎

从静态画像到动态行动——融合多种客户信号，生成按优先级排序的每日行动清单，提醒SA主动出击。

用户门店SA（每日"今日待办"推送）
场景：每日智能待办系统每天融合多种信号（沉默预警/重要日期/复购窗口/购后关怀节点），生成优先级排序的联系清单，每条附带客户画像摘要和建议话术

技术要点

• 多信号源融合：沉默预警（时序偏离检测）、重要日期（日历匹配）、复购窗口（购买周期建模）、购后节点（订单时间轴）——四类信号统一进入排序池
• 优先级排序算法：每条Moment的优先级 = 客户价值分（RFM）× 紧迫度分（距事件越近越高）× 预期响应概率（历史回复率），避免SA被大量提醒淹没
• 防打扰机制：同一客户同一时间段最多推送1条；多信号触发时自动合并（如"李太太同时命中沉默预警+生日临近"→ 合并为1条，优先展示生日）
• 跨Agent协同：Moment Agent决定"何时联系谁"→ Client Agent提供"这个人是谁"→ Voice Agent生成"怎么说"——Orchestration Agent统一编排

指标与评测

• 信号检测召回率 ≥ 90%：应触发的Moment中系统实际检测到的比例
• SA每日Moment处理率 ≥ 70%：SA在48小时内执行联系的比例
• Moment驱动的客户回复率 ≥ 20%：通过Smart Moments发起的联系获得客户回复的比例
• 预警客户挽留成功率 ≥ 15%：沉默预警后30天内恢复互动的客户比例
